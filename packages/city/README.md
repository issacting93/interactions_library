# @forge/city

Places: the city grammar and its tiles (grammar/), wave-function collapse, placement, terrain, towers and spires, patterns.

Needs: @forge/core, @forge/kit.

These are classic scripts: a page loads each with `<script src>` and it puts its name on `window` (in the order of what it needs). Nothing here imports anything yet; see `docs/PACKAGES.md`.

Scripts: `city-grammar-mesh.js`, `city-grammar.js`, `city-placement.js`, `city-wfc.js`, `creature-spire.js`, `forge-building.js`, `naqsh-pattern-engine.js`, `radial-lattice.js`, `rule-sets.js`, `spire-generator.js`, `terrain.js`, `tower-engine-gl2.js`, `tower-engine.js`, `tower-presets.js`.
