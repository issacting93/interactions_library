# @forge/motion

How bodies move: IK, gaits, skeleton, the physics body, walkers and their brains, rigs, solid limbs, and the built creatures (creatures/).

Needs: @forge/core, @forge/kit, @forge/parts.

These are classic scripts: a page loads each with `<script src>` and it puts its name on `window` (in the order of what it needs). Nothing here imports anything yet; see `docs/PACKAGES.md`.

Scripts: `appendage-solid.js`, `creature-body.js`, `creature-rig.js`, `creature-sprites.js`, `creature-walk.js`, `creatures/beasts.js`, `creatures/blender-qilin.js`, `creatures/chain.js`, `creatures/mystic-qilin.js`, `creatures/quad-mech.js`, `gaits.js`, `ground-walkers.js`, `ik.js`, `looks.js`, `skeleton.js`, `skin-leg.js`, `solid-look.js`, `species-rig.js`, `walker-brain.js`, `walker.js`, `world-brain.js`, `world-gen.js`.
