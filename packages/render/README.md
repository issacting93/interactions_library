# @forge/render

Drawing: the ecology renderer, the style recipes (Route looks), the Route scenery, creature looks and skins.

Needs: @forge/kit, @forge/parts, @forge/motion, @forge/ecology.

These are classic scripts: a page loads each with `<script src>` and it puts its name on `window` (in the order of what it needs). Nothing here imports anything yet; see `docs/PACKAGES.md`.

Scripts: `creature-look.js`, `ecology-render.js`, `holy-light.js`, `route-atmo-gl2.js`, `style-recipes.js`.
