# @forge/glyph

Scripts and sigils: the glyph system, xenoglyphs, sigil generator, script search.

Needs: @forge/core.

These are classic scripts: a page loads each with `<script src>` and it puts its name on `window` (in the order of what it needs). Nothing here imports anything yet; see `docs/PACKAGES.md`.

Scripts: `glyph-system.js`, `script-search.js`, `sigil-generator.js`, `xenoglyph-engine.js`.
