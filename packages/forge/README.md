# @forge/forge

The Forge workbench: the generator registry and its registrations, evolution (chimera, map-elites), mechs (mech/), the node graph, pixel effects, the gaze camera, the tower forge UI.

Needs: @forge/core, @forge/kit, @forge/city, @forge/glyph, @forge/render, @forge/ui.

These are classic scripts: a page loads each with `<script src>` and it puts its name on `window` (in the order of what it needs). Nothing here imports anything yet; see `docs/PACKAGES.md`.

Scripts: `chimera.js`, `forge-ai.js`, `forge-env.js`, `forge-generators.js`, `forge-overrides.js`, `forge-registry.js`, `gaze-camera.js`, `map-elites.js`, `mech/blade-mech.js`, `mech/creature-mech.js`, `mech/hex-mech.js`, `node-graph-engine.js`, `pixel-fx-engine.js`, `tower-forge-ui.js`.
