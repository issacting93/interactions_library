# @forge/kit

The creature kit as data: parts, outlines, looks, taxonomy, catalogue and the tools that build it (catalog/), the creature architecture and the species the tank swims.

Needs: @forge/core.

These are classic scripts: a page loads each with `<script src>` and it puts its name on `window` (in the order of what it needs). Nothing here imports anything yet; see `docs/PACKAGES.md`.

Scripts: `attach-points.js`, `creature-arch.js`, `creature-catalog.js`, `creature-cells.js`, `creature-classical.js`, `creature-record.js`, `data/core-outlines.js`, `data/creature-looks.js`, `data/creature-shapes.js`, `data/kit-plants-lines.js`, `ecology-species.js`, `maw-cells.js`, `mech-slots.js`.
