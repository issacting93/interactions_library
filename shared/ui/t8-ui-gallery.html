Accordion — native <details>, zero JS

What makes a feedback loop legal?
A loop is legal only if it passes through a DELAY node — its block of latency is what breaks the cycle. Everything else closing a loop is flagged illegal.
How is latency compensated?
Every node downstream of a source carries the maximum latency of the paths feeding it, computed by the topo-sort in patch-core.js's analyse().
Can a sidechain input take more than one cable?
No — patching a new cable into an SC port replaces whatever was there.
