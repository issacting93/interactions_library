WFC Patch — regenerate only what changed

A signal chain between a fixed INPUT and OUTPUT is treated as a Wave Function Collapse grid: each slot starts in superposition over Patch's own node types, a symbolic grammar prunes what's legal, and an intent preset (the neural stand-in) biases which legal option gets picked. Click any module to swap it — only the neighbours that are actually no longer legal re-collapse; everything else, pinned or not, is left untouched. Pieces reused as-is from tools/patch: node types, ports, cables, node cards.

R1 · ANCHORSSlot 0 is always INPUT, the last slot always OUTPUT — fixed, never re-collapsed.
R2 · VOCABULARYInterior slots draw from GAIN, TAPE SAT, DELAY, LIMITER — Patch's real 1-in/1-out module types.
R3 · NO REPEATA slot can't match either neighbour's module — the one local, pairwise constraint WFC propagates.
R4 · ONE DELAYAt most one DELAY anywhere in the chain — a global cardinality rule, checked everywhere at once.
R5 · LIMITER SLOTLIMITER, if it appears, must sit in the slot immediately before OUTPUT — a position-locked tile.
