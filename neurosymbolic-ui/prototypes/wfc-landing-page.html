WFC Landing Page

The page's own section grammar, not an invented one. 10 slots — HERO and CTA_FINAL fixed as anchors, 8 interior slots each resolving to one of 8 real section types or EMPTY (page length genuinely varies). Every section is built from shared/t8-ui.css and shared/hardware-ui.js — the same components in their own galleries, not placeholders. Click a slot's SWAP to try a different legal section there.

R1 · ANCHORSHERO is always first, CTA_FINAL always last.
R2 · PROBLEM BEFORE SOLUTIONPROBLEM, if present, precedes FEATURES, and stays in the first half of the page.PAS / PASTOR copywriting frameworks
R3 · PROOF STAYS UP TOPSOCIAL_PROOF, if present, lands within the first 3 sections after the hero."sat right next to the headline… not halfway down the page"
R4 · CTA REPEATSA repeat CTA immediately follows FEATURES or SOCIAL_PROOF — and can only ever follow them."repeat it… after features, after social proof"
R5 · PROOF BEFORE THE OFFERTESTIMONIALS, if present, sits immediately before PRICING.PASTOR: Testimonials → Offer
