Out of date

An object is out of date when something it was built from has been saved since. Recooking rebuilds it from the current version, then whatever was built on it, in order.

How each kind recooks

Tower from Bench: regenerated with the current rule set. Rig: bones rebuilt from the current attach points. City and species: they read their buildings and bases live, so recooking records the new versions.
