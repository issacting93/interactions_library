Node Card

One module on the canvas. It has an order badge, a name and a status LED in the header, jacks down each side, and mini knobs along the bottom. Height follows the port count and whether the module has parameters. The card is built once and updated in place, so knobs tween, the order badge pops when its number changes, and a red border flags a node stuck in an illegal loop.
