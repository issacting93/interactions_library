Patch Canvas

The stage. It shows the title, counts, graph status and PDC above a 900×600 dotted grid. On load the patch assembles: cards spring in, then cables draw on. Drag a header to move a node. Tap an output and a ghost cable trails the pointer; tap an input to land it. RESET springs every node home while the cables follow.
