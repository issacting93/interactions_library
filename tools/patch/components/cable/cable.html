PATCH / COMPONENTS / CBL-05

Cable

A patch cord: a bezier with horizontal tangents from an output to an input, with a 16 px invisible hit path. Kind sets the colour and dash pattern. While auditioning, cables flow. A new cable draws itself on from its output end (anime.js, outQuart).
