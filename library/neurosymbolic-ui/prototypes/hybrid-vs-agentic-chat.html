Hybrid vs agentic, in chat

Every message changes the query. Both assistants answer the same conversation with inline UI from the same Material-style widget library. The hybrid side decides whether each message refines the last request or switches to a new one, and anchors the reply’s structure only when it refines. The agentic side gets the same rules as guidelines and a checker.

Level 1 · Shell

Never regenerated

App bar, composer and navigation stay fixed for the whole conversation. Only the inline UI inside replies is generated.

Level 2 · Refine

Keep the skeleton

A follow-up on the same need keeps the previous reply’s length and the action bar’s slot. The content inside the widgets changes.

Level 3 · Switch

Keep the patterns

A new need releases the positional anchors, but the grammar still holds: the action bar sits under a product, and quick replies close every reply.
